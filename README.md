# Custom Assembler and Simulator

This project implements a custom **assembler** and **simulator** in Python for a **16‑bit Instruction Set Architecture (ISA)** designed for the CSE112 Computer Organization course.  
The ISA supports six instruction formats, seven general‑purpose registers, one FLAGS register, and an 8‑bit double‑byte‑addressable memory (512 bytes total).

## Assembler
The assembler reads an assembly program from **stdin** and produces its corresponding **16‑bit binary encoding**.  
It supports:

- All instruction types (A, B, C, D, E, F)
- Label resolution
- Variable handling (must be declared at the beginning)
- Immediate value validation (0–255)
- Register and opcode validation
- Error reporting with line numbers

If the program is valid, the assembler outputs machine code (one 16‑bit binary instruction per line).  
If errors exist, one descriptive error message is printed.

## Simulator
The simulator executes the binary generated by the assembler and models the architecture defined in the ISA.

It supports:

- Loading binary into memory (512 bytes initialized to 0)
- 7 general‑purpose registers + FLAGS
- 8‑bit Program Counter (PC)
- Cycle‑by‑cycle instruction execution
- Dumping register values after each instruction
- Halting only on the `hlt` instruction
- Tracking memory accesses and generating a **memory‑address vs cycle‑count scatter plot** (bonus)

## How to test 
* Go to the `automatedTesting` directory and execute the `run` file with appropriate options passed as arguments.
* Options available for automated testing:
	1. `--verbose`: Prints verbose output
	2. `--no-asm`: Does not evaluate the assembler
	3. `--no-sim`: Does not evaluate the simulator
 modify this accordingly.
